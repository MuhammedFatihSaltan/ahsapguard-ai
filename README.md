# AhşapGuard AI

> Yapay zekâ ve PatchCore ile ahşap ve kereste yüzeylerinde otomatik kusur ve anomali tespiti yapan endüstriyel kalite kontrol sistemi.

## 📌 Proje Hakkında
AhşapGuard AI; ahşap ve kereste yüzeylerinin görüntülerini analiz ederek normal yüzeylerden farklı bölgeleri belirleyen, olası kusurları anomali haritasıyla görselleştiren ve kalite kontrol sonucunu kullanıcıya sunan bir uygulamadır.

## 🛠️ Teknolojiler
- **Dil:** Python
- **Derin Öğrenme / AI:** PyTorch, PatchCore, Anomalib
- **Görüntü İşleme:** OpenCV, NumPy, Pillow
- **Arayüz:** Streamlit
- **Test / Kalite:** pytest

## 📁 Veri Kümesi
Bu projede MVTec AD (`wood` kategorisi) veri kümesi kullanılmaktadır.
